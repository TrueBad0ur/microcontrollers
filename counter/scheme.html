8-битный счётчик на ATtiny13A

Восемь чипов, каждый хранит один бит. Нажатие кнопки переключает BIT 0. Когда бит переходит из 1 в 0, это перенос: pin 3 дёргает pin 7 соседа слева, и тот переключает свой бит. RESET (pin 1 всех чипов на GND) сбрасывает счёт в 0. Обе кнопки на схеме можно нажимать.

Старшие биты 7–4

Младшие биты 3–0

точка — провода соединены горбик — пересекаются, НЕ соединены оранжевый — на проводе +5V (высокий уровень) LED1…LED8 — светодиод и резистор внутри LED-модуля, горит при 0 на пине метка Q3 и линия RST — общие провода между рядами

Каждый чип (одинаково для всех 8)

ПинПортКуда
1RSTобщий провод RST всех 8 чипов → кнопка RESET → GND
2PB3пин LED-модуля (BIT 0 → LED1 … BIT 7 → LED8)
3PB4Q → pin 7 чипа слева (у BIT 7 никуда)
4GNDшина GND
5PB0никуда
6PB1никуда
7PB2вход ← pin 3 чипа справа (у BIT 0 — кнопка на GND)
8VCCшина +5V

Что нужно

  • 8 × ATtiny13A, все с одной прошивкой
  • LED-модуль на 8 светодиодов, его VCC на +5V
  • 2 кнопки: счёт и RESET
  • Питание +5V / GND с USBasp (IDC 2 и IDC 10)

Как читать

LED8 … LED1 на модуле слева направо — число в двоичном виде, 0…255. После 255 снова 0. RESET или выключение питания — счёт сбросился.
